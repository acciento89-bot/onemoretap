# NavoTap Android / iOS parity gate

NavoTap is part of the 2026-09-13 Kamilunavo Android parity overhaul.

Before the next Google Play submission:

- Compare every Android screen/interaction against the current iOS product reference.
- Keep the game input reliability fixes; no tap may be silently lost because of UI gesture layering.
- Status/navigation bars must visually belong to the dark NavoTap surface and content must respect safe drawing insets.
- Launcher/start icon must match the Play icon exactly.
- Store screenshots must be captured from the exact reviewed Android build, never mocked.
- Validate purchases/restore, ad consent, DE/EN text and navigation.

NavoKids is explicitly outside this portfolio overhaul and is not affected by this document.
